PDF配置ツール 利用マニュアル
用意済みPDFを開く
想定シーン：オフィスプランの席番

図面の一部を切り出して、
席に番号を置く

全体レイアウトPDFからフロアや区画を切り取り、席の位置にオブジェクトを置いて連番付きPDFを作ります。色・形の変更、位置ずらし、整列、コピー＆ペーストまで、画面のボタン名どおりに説明します。

目次

  1. 起動と画面の見方
  2. 切り抜き・レイヤーで図面の一部をPDF化する
  3. 切り出した図面を取り込んで席に置く
  4. オブジェクトの色・形を変える
  5. 位置をずらす・整列する・コピー＆ペースト
  6. 番号付きPDFを出力する
  7. ショートカット

1. 起動と画面の見方

  1. ZIPを解凍し、index.html をダブルクリックしてブラウザで開きます（このファイル1つで起動できます）。
  2. ヘッダー左の 配置 と 切り抜き・レイヤー で作業画面を切り替えます。席番の配置は「配置」、図面の切り出しは「切り抜き・レイヤー」です。
  3. 作業名を入力して 保存 します。同じ作業名は履歴でグループ化されます。初期値5分の自動保存もあります。
同じ場所の index.html を開き直せば保存履歴が残ります。ファイルを別フォルダへ移すと別データ扱いになることがあります。

2. 切り抜き・レイヤーで図面の一部をPDF化する

全館や複数フロアが入った大きな図面から、「3F執務室だけ」を帳票サイズのPDFにする作業です。

  1. PDF読込 で、オフィス全体のレイアウトPDFを開きます。
  2. ヘッダーの 切り抜き・レイヤー を押します。配置用の左右パネルが消え、抽出用の操作が出ます。
  3. 帳票 でサイズ（例: A4）と向き（縦／横）を選び、範囲追加 を押します。現在ページに帳票比率の枠が乗ります。
  4. 枠をドラッグして執務室の上へ移動し、角ハンドルで拡縮します。机が枠内に収まるようにします。
  5. 左の「抽出エリア（出力順）」に枠が一覧されます。複数フロアなら枠を複数追加します。並び順が出力ページ順です。不要な枠は選んで 範囲削除 します。
  6. 元PDFにレイヤー（OCG）がある場合は左の「PDFレイヤー」で表示／非表示を切り替えます。寸法線だけ消したいときなどに使います。
  7. ヘッダー右の出力で、対象を 指定範囲 にし、PDF出力 を押します。帳票サイズに拡大した切り出しPDF（*_edited.pdf）が保存されます。下絵はパス／文字のままです。
切り出し直後のPDFには、まだ席番号は入っていません。番号は次の「配置」作業で載せます。

3. 切り出した図面を取り込んで席に置く

  1. 配置 画面に戻します。
  2. PDF読込 で、手順2で出力したフロア図PDFを開きます。配置データがある場合は消すか残すかを確認されます。新しい図面なら消して構いません。
  3. 左のグループマスターで 新規 を押し、グループを作ります。グループは「席番号シールの原版」です。例: グループ名「一般席」、基本テキスト {auto:000}、開始番号 1。
  4. カードをクリックして、これから置くグループを選びます。
  5. ヘッダーの 登録 を押し、机の上をクリックします。クリックした位置にオブジェクトが1つ置かれ、連番が進みます。
  6. 右の「配置済みリスト」に番号順で並びます。ハンドルをドラッグすると連番（order）が入れ替わります。
グループ未作成のまま登録すると警告が出ます。先に 新規 で原版を作ってください。部署ごとに色を変えたいときは、グループを複数作ります（例: 一般席＝青円、管理職＝茶四角）。

基本テキスト（連番の書き方）

記法席番での使い方
{auto}1, 2, 3…（開始番号＋順番）
{auto:000}001, 002… ゼロ埋めで揃える
{auto:A-Z}A, B, C… アルファベット循環
{auto:A01-A10}A01〜A10 のような文字＋数字

4. オブジェクトの色・形を変える

見た目はまずグループ設定で一括変更します。特定の席だけ変えたいときは、オブジェクトをダブルクリックして個別上書きします。

四角形
円形
三角形
星形
一本線

グループでまとめて変える（推奨）

  1. 左のカードで対象グループを選びます。
  2. 「枠の形」で 四角形 / 円形 / 三角形 / 星形 / 一本線 を選びます。席番は円形か四角形が扱いやすいです。
  3. 幅・高さ（pt）でシールサイズを決めます。「自動幅」をオンにすると文字量に合わせて拡縮します。
  4. 「枠線描画」で枠の有無、「線の太さ」「枠線色」で輪郭を決めます。
  5. 「文字サイズ」「文字色」「フォント」で番号の見た目を決めます。画面プレビュー用です。PDFで「番号もオブジェクト」出力するときは埋め込みフォントは Noto Sans JP になります。
  6. 「背景色」と「背景不透明度 (0-1)」で塗りを決めます。不透明度 0 は透明（机の絵が透ける）、1 は塗りつぶしです。席を目立たせるなら 0.8〜1、図面を残したいなら 0.2〜0.5 が目安です。
  7. 一本線を選んだときだけ、始点・終点形状（なし / 矢印 / 丸）と端点サイズが出ます。動線や向きの指示に使います。
グループ設定を変えると、個別上書きしていない席へ一括反映されます。よく使う見た目は この内容を初期グループにする で保存すると、次の「新規」から同じ設定で作れます。

1席だけ色や形を変える

  1. 選択 モードで対象をクリックするか、リストをダブルクリックします。「アイテム詳細設定」が開きます。
  2. 変えたい項目のチェック（枠の形、枠線色、文字色、背景色 など）をオンにしてから値を変更します。チェックを入れた項目だけグループ設定を上書きします。
  3. 位置は同じ画面の X / Y（pt）でも数値指定できます。

5. 位置をずらす・整列する・コピー＆ペースト

位置をずらす

  1. 選択 を押し、オブジェクトをクリックします。ドラッグで机の中心へ寄せます。
  2. 複数をまとめて動かすときは、Shift+クリック、または何もないところをドラッグして範囲選択します。
  3. キーボードの矢印キーで微調整します。移動量は右サイドバー「矢印キー移動量 (pt)」です（初期 1.0pt）。
  4. 単一選択時は角ハンドルでリサイズできます。一本線は端点をドラッグします。
  5. グループまたはアイテムの「ロック」がオンだと、移動・リサイズ・整列・端点編集ができません。

整列

同じ列の机に番号を揃えるときに使います。複数選択が必要です。均等割りは3件以上です。ロック中は対象外です。

場所ボタン席番での使い方
横整列左 / 中央 / 右 / 均等横一列の机で、番号の左右位置をそろえる。均等は席間隔を等間隔にする
縦整列上 / 中 / 下 / 均等縦一列の机で上下をそろえる（PDF座標は上が +Y）

コピー＆ペースト

  1. コピーしたい席を選択します。
  2. 右リストの コピー、または Ctrl+C（Mac は Cmd+C）を押します。
  3. 貼り付け または Ctrl+V で複製されます。少しずらした位置に置かれ、連番はグループの並びに合わせて振り直されます。
  4. 同じ並びに机が続くときは、1席の見た目を決めてからコピーし、貼り付け後に整列すると速いです。
貼り付け先に同じグループがあれば、そのグループに属します。元に戻すときは 戻す か Ctrl+Z です。

6. 番号付きPDFを出力する

席を置き終わったら、ヘッダー右の「出力」から完成稿を書き出します。

  1. 番号の重ね方を選びます。番号もオブジェクト（既定）は拡大しても番号がぼけにくく、文字を選択できます。番号は画像 は番号だけ透過PNGで重ねます。下絵の図面はどちらも全面画像化しません。
  2. 出力対象を選びます。フロア図1枚なら 全ページ。切り抜き枠のまま出したいときだけ 指定範囲 です。
  3. 「表示レイヤーのみ」をオンにすると、切り抜き画面で非表示にしたPDFレイヤーは出ません。
  4. PDF出力 を押すと *_edited.pdf がダウンロードされます。

このマニュアル自体のPDF化

画面上の このマニュアルをPDF出力 を押すと、ブラウザの印刷ダイアログが開きます。送信先（プリンター）で PDFに保存 / Microsoft Print to PDF を選び、保存してください。用紙は A4 想定です。
