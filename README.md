# PDF配置ツール

PDFを下絵にして、グループで決めたオブジェクトを配置し、連番付きで出力するブラウザツールです。プレビューは pdf.js、出力は pdf-lib、保存はブラウザの IndexedDB を使います。同時に開ける PDF は1つです（複数ページには対応）。

## 起動

`index.html` をブラウザで開きます。外部ライブラリは CDN から読み込みます。

## 出力の検証（Node）

ブラウザなしで、ネイティブ PDF 描画（元ページ保持・非画像・Noto 埋め込み）を確認できます。

```bash
npm install pdf-lib@1.17.1 @pdf-lib/fontkit@1.1.1
node tests/native-pdf-export.node.mjs
```

## 基本の流れ

1. **PDF読込** で下絵を開く。
2. 左の **新規** でグループを作り、形・文字・連番を設定する。
3. **登録** モードでキャンバスをクリックし、オブジェクトを置く。
4. **選択** モードで移動・リサイズ・整列する。
5. **保存** でブラウザにバージョン保存。**PDF出力** で完成稿を書き出す。

## ショートカット

| 操作 | 方法 |
|------|------|
| 選択 / 登録 | ヘッダーの「選択」「登録」 |
| 元に戻す | Ctrl+Z（Mac は Cmd+Z） |
| やり直し | Ctrl+Y または Ctrl+Shift+Z |
| 微調整 | 矢印キー（移動量は右サイドバー） |
| 削除 | Delete / Backspace（入力中は除く） |
| 複数選択 | Shift+クリック、または空欄ドラッグ |
| 詳細設定 | オブジェクトをダブルクリック |
| 閉じる / 選択解除 | Esc |

画面の **操作ヘルプ** からも同じ説明を開けます。

## 機能と操作

### 作業・保存

- **作業名**: ヘッダー左の入力欄。
- **保存**: IndexedDB にタイムスタンプ付きの **新規バージョン** として保存します（上書きではありません）。
- **データ管理**:
  - 保存履歴: 復元 / 削除。現在の状態を新規保存もできます。
  - JSON入出力: 現在ページまたは全ページの配置データをコピー・保存・上書き復元。
  - 完全ファイル退避: PDF 本体を含む JSON を PC に保存 / 復元。

### PDF

- **PDF読込**: 新しい下絵を開きます。配置データがある場合、消すか残すかを確認します。
- **PDF差替**: 下絵だけ差し替え、配置は残します（元 PDF の更新向け）。
- **前へ / 次へ**: ページ切替。配置はページごとに保持されます。
- **PDF出力**: 元ページを残したまま、番号オブジェクトをパス／文字として重ねた `*_edited.pdf` をダウンロードします（ラスター画像ではありません）。埋め込みフォントは Noto Sans JP です（游ゴシック等は埋め込めないため、UI のフォント指定は画面プレビューのみに効きます）。

### 表示

- **− / ＋** で 10% ずつ拡大縮小。数値入力は 50–800%。
- ヘッダーのステータスに、モード・選択件数・ズームが表示されます。

### モード

- **選択**: クリックで選択、Shift で複数選択、空欄ドラッグで範囲選択。ドラッグで移動。単一選択時はハンドルでリサイズ、線は端点ドラッグ。
- **登録**: アクティブなグループのオブジェクトを、クリック位置に1つ置きます。グループ未作成時は警告します。

### グループ（左サイドバー）

グループは見た目の原版です。設定を変えると、所属オブジェクトへ一括反映します（個別上書きした項目は除く）。

- **新規**: グループを追加して設定パネルを開く。
- **カード選択**: 登録モードで置くグループを指定。
- **設定**: 形、サイズ、自動幅、枠線、文字、フォント、背景、zIndex、基本テキスト、開始番号、ロック、非表示。一本線のときは始点・終点形状と端点サイズ。
- **削除**: グループと所属オブジェクトをまとめて削除（確認あり）。Undo 対象。
- **ロック**: そのグループへの配置・移動・リサイズ・整列・端点編集を禁止（設定変更は可）。
- **非表示**: キャンバス上に描かない。範囲選択の対象外。

### オブジェクト（キャンバス・右リスト）

- リストはグループごとに開閉。ハンドルをドラッグすると連番順（`order`）が変わります。
- 検索は表示テキスト・元テキスト・グループ名・ID。
- リストの ×、または Delete / Backspace で削除。
- ダブルクリックで個別プロパティ。チェックを入れた項目だけグループ設定を上書きします。
- アイテムのロックは移動・リサイズ・整列・端点・キーボード削除を禁止します。

### 文字と連番

グループの基本テキスト（または個別上書き）に次の記号を書けます。番号はグループ内の `order` 順です。

| 記法 | 内容 |
|------|------|
| `{auto}` | 開始番号 + 順番 |
| `{auto:000}` | ゼロ埋めで連番 |
| `{auto:A-Z}` | アルファベット循環 |
| `{auto:A01-A10}` | 文字＋数字の範囲 |

### 整列

複数選択時（均等割りは3件以上）。ロック中のオブジェクトは対象外です。

- 横: 左 / 中央 / 右 / 均等
- 縦: 上 / 中 / 下 / 均等（PDF 座標は上が +Y）

### 取り消し

配置・移動・グループ変更などは Undo / Redo できます。対象はグループとオブジェクトです（PDF 本体・ズームは含みません）。

## ファイル構成

- `index.html` / `style.css`: 画面
- `main.js`: UI 操作
- `AppCore.js`: PDF 描画・保存・出力
- `PdfNativeExport.js`: PDF へのパス／テキスト描画と Noto Sans JP 埋め込み
- `EditorModels.js`: データ形
- `DBManager.js`: IndexedDB
- `CoordinateConverter.js`: PDF 座標と画面座標
